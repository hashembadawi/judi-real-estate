# جودي لتطوير العقارات والإنشاءات

مشروع Next.js باستخدام App Router وTypeScript وTailwind CSS، مع دعم العربية
والإنجليزية والتركية عبر `next-intl`. اللغة الافتراضية هي العربية؛ الروابط
متاحة على `/ar` و`/en` و`/tr`.

## بدء التطوير

```bash
npm install
npm run dev
```

ملفات التوجيه والرسائل موجودة في `src/i18n/` و`messages/`.

## النشر على Render كـ Static Site

المشروع مُعدّ للتصدير الثابت عبر `npm run build`، وتُنشأ الملفات الجاهزة للنشر
في مجلد `out`. عند إنشاء Static Site على Render استخدم:

- **Build Command:** `npm ci && npm run build`
- **Publish Directory:** `out`

الصفحات تُولّد للغات العربية والإنجليزية والتركية، وصفحات المشاريع تُولّد
للمشاريع الموجودة وقت البناء. أعد البناء والنشر بعد إضافة مشروع جديد. التحويل
من `/` إلى `/ar/` موجود في `public/index.html`.
